# 🎙️ 会議の文字起こし＆議事録作成ツール（Google Colab版）

Googleドライブに置いた会議の録音から、**文字起こし**と**議事録（要約・決定事項・ToDo）**を自動で作るツールです。
**数時間の長い会議**にも対応しています。

**文字起こしも要約も、すべてGoogle Colabの中（無料のGPU）で処理します。外部AIサービスのAPIキーや利用料金は不要です。**

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/tomoshou/Transcription-and-Summarization-Tool/blob/main/meeting_transcriber.ipynb)

> ※ 上のボタンはリポジトリが公開設定で、`main` ブランチにファイルがある場合に使えます。
> 非公開の場合は `meeting_transcriber.ipynb` をダウンロードし、[Google Colab](https://colab.research.google.com/) の「ファイル」→「ノートブックをアップロード」で開いてください。

## できること

| 出力ファイル | 内容 |
|---|---|
| `議事録.md` / `議事録.docx` | 会議の要約・議題ごとの議論・決定事項・ToDo表・未決事項・タイムライン |
| `区間ごとの詳細メモ.md` | 区間（約15〜20分）ごとの詳しい整理メモ |
| `文字起こし.txt` | `[01:23:45] 発言内容` 形式の時刻付き全文 |
| `字幕.srt` | 動画プレーヤーで使える字幕 |
| （おまけ） | 「〇〇さんの担当タスクは？」のように会議内容へ質問 |

## しくみ（ざっくり）

```
 Googleドライブの録音
        │
        ▼
 ① 10分ずつ区切って文字起こし（音声認識AI「Whisper large-v3」）
    └ 区切りごとにドライブへ保存 → 接続が切れても続きから再開
        │
        ▼
 ② 約15〜20分ごとに、要約AI「Qwen3-8B」が整理メモを作成
    └ これも区間ごとに保存 → 続きから再開できる
        │
        ▼
 ③ メモをまとめて、1つの議事録に仕上げる
    （会議が長くメモが多すぎる場合は、隣り合うメモを段階的に統合してから仕上げる）
        │
        ▼
 Googleドライブに結果を保存
```

使っているAIはどちらも無料で公開されているモデルで、ColabのGPU上で動きます。

| 役割 | モデル | ライセンス |
|---|---|---|
| 文字起こし | [Whisper large-v3](https://huggingface.co/Systran/faster-whisper-large-v3)（faster-whisper） | MIT |
| 要約（標準） | [Qwen3-8B](https://huggingface.co/Qwen/Qwen3-8B) | Apache 2.0 |
| 要約（速さ重視） | [Qwen3-4B-Instruct-2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507) | Apache 2.0 |
| 要約（日本語特化） | [Llama-3.1-Swallow-8B-Instruct-v0.5](https://huggingface.co/tokyotech-llm/Llama-3.1-Swallow-8B-Instruct-v0.5) | Llama 3.3 / Gemma 利用規約 |

- **長時間対応の工夫**
  - 録音も要約も小分けに処理して1つずつ保存するので、Colabの接続が切れても最初からやり直す必要がありません。
  - 区切り目で言葉がちぎれないよう、各区切りの最後の発言は次の区切りで改めて認識しています。
  - 要約AIが一度に読める量には限りがあるため、「区間ごとに整理 → 段階的に統合 → 全体のまとめ」の順に処理します。
- **精度の工夫**
  - 無音部分を自動で飛ばし、無音時に起こりがちな「ありもしない文」の出力を防ぎます。
  - 専門用語・人名を登録すると、認識精度が上がります。

> 📝 Colabで動く無料の要約AIは、有料の大型AI（ChatGPTやClaudeなど）に比べると文章の質は控えめです。
> 決定事項などの重要な内容は、`区間ごとの詳細メモ.md` や `文字起こし.txt` もあわせて確認してください。

## 準備するもの

- **Googleアカウント**だけです（Colab と Googleドライブを使います）

## 使い方

1. Colabでノートブックを開く
2. メニュー「ランタイム」→「ランタイムのタイプを変更」→ **T4 GPU** を選ぶ
3. 録音ファイルを Googleドライブ に入れる
4. セル①〜⑤を順番に実行（③の設定欄で録音ファイルのパスを指定）

詳しい説明はノートブックの中に書いてあります。

## 処理時間の目安（無料のT4 GPU）

| 録音の長さ | 文字起こし | 議事録作成 |
|---|---|---|
| 1時間 | 約5〜10分 | 約10〜20分 |
| 3時間 | 約15〜30分 | 約30〜50分 |

※ 初回のみ、AIモデルのダウンロードに追加で5〜10分ほどかかります。
※ 上記は目安で、会話の量によって変わります。
※ Colab無料版は、操作しないまま長時間放置したり、1回の利用が長時間（最大12時間程度）に及んだりすると接続が切れることがあります。切れた場合は①〜③を実行してから④（または⑤）を再実行すれば続きから再開します。

## 開発者向け

ノートブックは `tools/build_notebook.py` から生成しています。セルの中身を変更したら次を実行してください。

```bash
python tools/build_notebook.py
```

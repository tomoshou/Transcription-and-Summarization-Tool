# 🎙️ 会議の文字起こし＆議事録作成ツール（Google Colab版）

Googleドライブに置いた会議の録音から、**文字起こし**と**議事録（要約・決定事項・ToDo）**を自動で作るツールです。
**数時間の長い会議**にも対応しています。

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/tomoshou/Transcription-and-Summarization-Tool/blob/main/meeting_transcriber.ipynb)

> ※ 上のボタンはリポジトリが公開設定で、`main` ブランチにファイルがある場合に使えます。
> 非公開の場合は `meeting_transcriber.ipynb` をダウンロードし、[Google Colab](https://colab.research.google.com/) の「ファイル」→「ノートブックをアップロード」で開いてください。

## できること

| 出力ファイル | 内容 |
|---|---|
| `議事録.md` / `議事録.docx` | 会議の要約・議題ごとの議論・決定事項・ToDo表・未決事項・タイムライン |
| `区間ごとの詳細メモ.md` | 30分ごとの詳しい整理メモ |
| `文字起こし.txt` | `[01:23:45] 発言内容` 形式の時刻付き全文 |
| `字幕.srt` | 動画プレーヤーで使える字幕 |
| （おまけ） | 「〇〇さんの担当タスクは？」のように会議内容へ質問 |

## しくみ（ざっくり）

```
 Googleドライブの録音
        │
        ▼
 ① 10分ずつ区切って文字起こし（Whisper large-v3 / Colabの無料GPU）
    └ 区切りごとにドライブへ保存 → 接続が切れても続きから再開
        │
        ▼
 ② 30分ごとに Claude が整理メモを作成（決定事項・ToDoなどを抽出）
        │
        ▼
 ③ 全メモ＋文字起こし全文から、Claude が1つの議事録にまとめる
        │
        ▼
 Googleドライブに結果を保存
```

- **長時間対応の工夫**
  - 録音を小分けに処理し、1区切りごとに保存するので、Colabの接続が切れても最初からやり直す必要がありません。
  - 区切り目で言葉がちぎれないよう、各区切りの最後の発言は次の区切りで改めて認識しています。
  - 要約も「30分ごとの整理 → 全体のまとめ」の2段階なので、長い会議でも細部が抜け落ちにくくなっています。
- **精度の工夫**
  - 無音部分を自動で飛ばし、無音時に起こりがちな「ありもしない文」の出力を防ぎます。
  - 専門用語・人名を登録すると、認識精度が上がります。
  - Claudeには「音声認識の誤変換を文脈で直す」「記録に無いことは書かない」よう指示しています。

## 準備するもの

1. **Googleアカウント**（Colab と Googleドライブ）
2. **Claude APIキー**（要約に使用。[Anthropic Console](https://console.anthropic.com/) で作成）
   - 費用の目安：1時間の会議で数十円程度（Opus使用時。実行後に概算額を表示します）
   - Haikuモデルを選ぶとさらに安くなります

## 使い方

1. Colabでノートブックを開く
2. メニュー「ランタイム」→「ランタイムのタイプを変更」→ **T4 GPU** を選ぶ
3. 画面左の **🔑（シークレット）** に `ANTHROPIC_API_KEY` という名前でAPIキーを登録し、「ノートブックからのアクセス」をオン
4. 録音ファイルを Googleドライブ に入れる
5. セル①〜⑤を順番に実行（③の設定欄で録音ファイルのパスを指定）

詳しい説明はノートブックの中に書いてあります。

## 処理時間の目安（T4 GPU・large-v3）

| 録音の長さ | 文字起こし | 議事録作成 |
|---|---|---|
| 1時間 | 約5〜10分 | 約2〜5分 |
| 3時間 | 約15〜30分 | 約5〜10分 |

※ Colab無料版は、操作しないまま長時間放置すると接続が切れることがあります。切れた場合は①〜③を実行してから④（または⑤）を再実行すれば続きから再開します。
